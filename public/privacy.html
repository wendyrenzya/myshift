Kebijakan Privasi MyShift

Terakhir diperbarui: 16 Agustus 2026

MyShift adalah aplikasi penjadwalan shift yang berjalan sepenuhnya di perangkat kamu. Halaman ini menjelaskan data apa saja yang diproses MyShift dan bagaimana MyShift memperlakukannya, termasuk saat kamu memilih menyambungkan Google Drive.

Data yang tersimpan di perangkat kamu

Semua data jadwal — nama personil, jadwal shift, catatan, dan riwayat cuti — tersimpan langsung di penyimpanan lokal browser kamu (IndexedDB). Data ini tidak pernah dikirim ke server MyShift, karena MyShift tidak punya server atau database sendiri. Tidak ada akun yang dibutuhkan untuk memakai MyShift.

Integrasi Google Drive (opsional)

Kalau kamu memilih menyambungkan Google Drive untuk fitur Backup/Restore, berikut yang perlu kamu tahu:

  • MyShift meminta izin akses dengan scope drive.file — scope paling sempit yang tersedia dari Google, artinya MyShift hanya bisa melihat atau mengubah file yang MyShift sendiri buat di Drive kamu (satu file bernama myshift-backup.json), dan tidak bisa mengakses file lain di Drive kamu.
  • Proses backup dan restore terjadi langsung antara browser kamu dan server Google — file backup tidak pernah melewati atau tersimpan di server MyShift, karena memang tidak ada server tersebut.
  • Sesi login Google bersifat sementara (session-only) dan tidak disimpan permanen oleh MyShift. Kamu mungkin perlu login ulang di sesi berikutnya.
  • Kamu bisa memutus akses ini kapan saja lewat tombol "Putuskan Google Drive" di aplikasi, atau lewat halaman izin akun Google kamu.

Berbagi data ke pihak ketiga

MyShift tidak menjual, menyewakan, atau membagikan data kamu ke pihak ketiga mana pun. MyShift juga tidak menggunakan data kamu untuk iklan atau pelacakan.

Kontak

Ada pertanyaan soal privasi? Hubungi support@myshift.my.id.
